# MailMagic

An intelligent email management dashboard that helps organize, categorize, and automate email responses using AI-powered magic ✨

## Features

- 📧 Smart email categorization and tagging
- 🤖 AI-powered email response suggestions
- 📊 Real-time dashboard analytics
- 🔍 Advanced search and filtering
- 📎 Attachment management
- ⭐ Priority inbox sorting
- 🏷️ Custom label creation

## Tech Stack

- **Frontend**: React.js with Tailwind CSS
- **Backend**: Node.js / Express (or Python/FastAPI)
- **Database**: MongoDB / PostgreSQL
- **Authentication**: JWT / OAuth 2.0

## Installation

```bash
git clone https://github.com/TanviNema1/MailMagic.git
cd MailMagic
npm install
npm start
```

## Environment Variables

```env
EMAIL_SERVICE_HOST=smtp.gmail.com
EMAIL_SERVICE_PORT=587
EMAIL_USER=your-email@gmail.com
EMAIL_PASSWORD=your-app-password
JWT_SECRET=your-secret-key
```

## Usage

1. Login with your email credentials
2. Dashboard shows all incoming emails
3. Use AI suggestions to draft responses
4. Create custom filters and rules
5. Track email analytics and response times
